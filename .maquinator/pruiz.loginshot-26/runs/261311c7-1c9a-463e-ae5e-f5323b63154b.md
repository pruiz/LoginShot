## Change Summary

Implemented exposure warmup and focus centering from zicojiao's commit (f269009) as configurable features in LoginShot. The implementation adds two new YAML settings under `capture:`:
- `exposureWarmupEnabled` (bool, default: `true`) — enables warmup pipeline before still capture
- `exposureWarmupDuration` (float seconds, default: `2.0`) — how long to run warmup

Key changes:
1. **AppConfig.swift** - Added `exposureWarmupEnabled` and `exposureWarmupDuration` to `CaptureConfig` with defaults and validation (duration clamped to >= 0).
2. **AppDelegate.swift** - Propagates the new config values to `CaptureService.captureJPEG` for both normal capture and camera verification paths.
3. **CaptureService.swift** - Added `exposureWarmupEnabled` and `exposureWarmupDuration` parameters through the call chain (`captureJPEG` → `OneShotCapture.perform` → initializer). In `OneShotCapture.run()`:
   - When enabled: Adds `AVCaptureVideoDataOutput` to session, starts session, configures center-weighted exposure metering (iOS only, guarded by `#if !os(macOS)`), waits `exposureWarmupDuration` seconds for auto-exposure/white-balance to settle, then captures still image.
   - When disabled: Preserves original behavior — brief 500ms stabilization sleep after session start.
4. **ConfigLoader.swift** - Parses both new settings with backward-compatible defaults.
5. **ConfigWriter.swift** - Includes both settings in sample YAML (with comments) and serialization. **Fixed precision loss**: Changed serialization from `String(format: "%.1f", ...)` to Swift's default Double interpolation to preserve full precision (e.g., 2.25 stays 2.25, not rounded to 2.2).
6. **MockCaptureService.swift** - Updated to match expanded protocol with new parameters, recording them for test verification.
7. **README.md** - Documented both settings with defaults table, YAML example, and behavior description.

All changes are backward compatible: when `exposureWarmupEnabled: false`, the original 500ms stabilization sleep behavior is preserved.

## Limitations

- **macOS-only center exposure**: The `configureCenterExposure` and `lockExposureAtCurrent` helpers are guarded by `#if !os(macOS)` as in the original zicojiao commit, so focus centering only applies on iOS. On macOS, only the warmup delay (running the video pipeline) takes effect. This is appropriate since macOS AVFoundation doesn't expose the same exposure metering controls.

- **No new unit tests for warmup behavior**: While the configuration parsing/serialization is covered by existing tests, the OneShotCapture warmup logic itself is not directly unit-tested due to its dependence on AVFoundation hardware. Integration testing would require a physical camera. This is a known gap that could be addressed in follow-up work with a more sophisticated test double.

- **Warmup latency**: When enabled (default), capture latency increases by ~2 seconds (configurable). Users who prioritize speed over exposure quality can disable it via `exposureWarmupEnabled: false` to retain the original 500ms behavior.
