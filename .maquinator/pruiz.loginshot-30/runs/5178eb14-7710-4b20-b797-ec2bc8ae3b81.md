## Change Summary

Implemented configurable exposure warm-up and focus/exposure centering support in the LoginShot capture pipeline, using the upstream warm-up approach as the base but adapting it to the current codebase so operators can tune or disable it in YAML instead of hard-coding the behavior. The capture service now supports optional pipeline priming via a temporary video output, optional center-weighted exposure metering, and a configurable warm-up duration in milliseconds.

The configuration model, loader, writer, README, and tests were updated together so the new behavior is defaulted safely, validated, persisted, and documented consistently. AppDelegate and test mocks were also updated so the new capture settings are threaded through the app's normal capture and camera verification flows.

## Limitations

- Validation here is build- and unit-test-based; there was no hardware camera smoke test in this harness, so real-world tuning of the default 2000 ms warm-up may still vary by webcam and lighting conditions.
- The implementation centers exposure metering, which matches the referenced upstream work and the practical AVFoundation behavior used here, but it does not introduce a separate autofocus-point control path beyond existing device behavior.
- Adding the temporary video output when warm-up or center metering is enabled slightly increases capture-session complexity and may affect capture latency on some hardware.

## Summary

Implemented the camera-capture quality improvement requested in this ticket by bringing over the upstream exposure warm-up idea and adapting it to LoginShot's current configuration-driven design.

### What changed
- Added new YAML-configurable capture settings:
  - capture.exposureWarmUpEnabled
  - capture.exposureWarmUpMilliseconds
  - capture.centerMeteringEnabled
- Updated the AVFoundation capture pipeline so it can:
  - briefly prime the camera pipeline before still capture,
  - meter exposure from the center of the frame,
  - and do both behaviors conditionally based on config.
- Wired the new settings through normal capture flow and camera verification flow.
- Updated config parsing, validation, config writing/sample generation, tests, and README documentation.

### Behavior
By default, LoginShot now keeps the new behavior enabled with a 2-second warm-up and center metering, which should help with webcams that produce a darker first frame before exposure settles. If a deployment prefers the old behavior or needs different timing, the new settings can be adjusted or disabled in config.yml.
